# DepthOfFieldX
Real-time scene rendering with fast depth-of-field (DoF) approximation using XUSG based on DirectX 12 or Vulkan.

Non-ML version of fast DoF based on my PG2024 paper: Fast Approximation to Large-Kernel Edge-Preserving Filters by Recursive Reconstruction from Image Pyramids

![Scene result](https://github.com/StarsX/DepthOfFieldX/blob/master/Doc/Images/DepthOfFieldX.jpg "DoF rendering result")

Hot keys:

[F1] show/hide FPS

[Space] pause/play animation
